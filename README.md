# CodeAlpha_BasicChatbot

A simple rule-based Python chatbot built for the CodeAlpha Python Programming Internship.

## Project Overview
This project is a console-based chatbot designed to practice Python fundamentals[span_0](start_span)[span_0](end_span). It listens for specific user inputs and responds with predefined answers using basic control flow.

## Features
* **Interactive Loop:** Keeps the conversation running until you type an exit command.
* **Rule-Based Responses:** Uses `if-elif` statements to match user greetings and questions[span_1](start_span)[span_1](end_span).
* **Simple Console I/O:** Clean text-based input and output[span_2](start_span)[span_2](end_span).

## Concepts Used
* Python Functions
* `while` Loops
* `if-elif-else` Statements
* Console Input/Output (`input()` and `print()`)[span_3](start_span)[span_3](end_span)
